# ISLES'26 submission image dependencies.
#
# DERIVATION
#   Versions are taken from the training environment (pip freeze) so that the container runs
#   the same code paths that produced the checkpoints. Only the packages actually imported at
#   inference time are listed; pip resolves the transitive dependencies of nnunetv2
#   (acvl_utils, batchgenerators, batchgeneratorsv2, blosc2, connected-components-3d,
#   dynamic_network_architectures, einops, scipy, tqdm) on its own.
#
# DELIBERATE EXCLUSIONS
#   torch, torchvision, triton, nvidia-*   supplied by the base image. The virtualenv is
#                                          created with --system-site-packages, so pip treats
#                                          the torch requirement of nnunetv2 as satisfied and
#                                          does not substitute a CPU wheel. Pinning them here
#                                          would conflict with the CUDA build already present.
#   jupyterlab, notebook, ipykernel, marimo    development tooling
#   matplotlib, seaborn, plotly, altair        plotting, unused at inference
#   pandas, scikit-learn, umap-learn, numba    benchmark and analysis only
#   panoptica                                  offline metric computation only
#   timm, huggingface_hub, safetensors         not used by this pipeline
#
# VERIFICATION AFTER BUILD
#   podman run --rm --entrypoint python <tag> -c \
#     "import torch, nnunetv2, SimpleITK, nibabel, skimage; print(torch.version.cuda)"
